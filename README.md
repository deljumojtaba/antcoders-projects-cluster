# antcoders-projects-cluster

Infrastructure for the Antcoders projects: a 3-node k3s cluster on Hetzner
running Kelime Savaşı, Kinmemo, Antcoders Assist and antcoders.dev.

Everything lives in [`infra/`](infra/). Start with [`infra/README.md`](infra/README.md)
for the layout, the runbook and day-to-day commands.

The application code is in each project's own repository; this repo only holds
how they run.
